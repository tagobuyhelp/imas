30. Image Requirements
Use high-quality licensed imagery for hero, each specialisation, internship, Dubai/Singapore/Thailand/Bali and
placement/corporate environments. Avoid low-quality generic stock.
31. Performance
Compress images; use WebP/AVIF where supported; lazy-load below-fold images; minimise third-party scripts;
optimise fonts; protect Core Web Vitals; prevent layout shifts.
32. Accessibility
Keyboard-accessible tabs; ARIA tab roles; visible focus; alt text; sufficient contrast; accessible accordions; accessible
buttons; semantic heading hierarchy.
33. CMS Requirements
Make programme information, fees, eligibility, admission dates, placement metrics, curriculum, tools, immersion
destinations, Expert Testimonials and FAQs editable without code changes.
